# 🎵 Customer Churn Analysis Dashboard

A Power BI dashboard that analyzes customer churn for a music streaming application. The dashboard provides insights into user behavior, subscription plans, payment methods, demographics, device usage, and network performance to identify factors influencing customer churn.

---

## 📌 Project Overview

This dashboard helps answer questions such as:

- What is the overall churn rate?
- Which subscription plan experiences the highest churn?
- Which payment methods are most common?
- How does churn vary across age groups and gender?
- Does network type affect churn?
- Which music genres have higher churn?
- How do buffering times influence churn?

## 📈 Key Insights

- Overall churn rate is **30.70%**
- Family plan shows relatively stable retention.
- Users experiencing longer buffering times tend to churn more.
- Network quality impacts customer retention.
- Churn differs across age groups and music genres.

## 📂 Dataset

The dataset represents customer activity for a music streaming platform and includes information such as:

- Customer Demographics
- Subscription Plans
- Payment Methods
- Device Type
- Network Type
- Buffering Time
- Music Genres
- Customer Churn Status
