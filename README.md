# 📂 Featured Projects

## 📱 PhonePe Transaction Analytics Dashboard

An interactive Power BI dashboard that analyzes digital payment transactions and user behavior.

### Highlights

- Analyzed **300K+ transactions** with a total transaction value of **₹3.47 Billion**
- Built KPIs for transaction amount, transaction count, success rate, user growth, and new users
- Developed interactive visualizations for service-wise analysis, payment status, age groups, and top users
- Implemented dynamic DAX measures, custom tooltips, and time intelligence calculations

**Tools Used:** Power BI • DAX • Power Query

📁 Folder: `Phone-Pe_Transaction_Analytics_Dashboard`
