# 👨‍💼 HR Analytics Dashboard | Power BI

An interactive HR Analytics Dashboard built using **Power BI** to monitor employee attendance, work-from-home trends, and sick leave patterns. The dashboard provides HR teams and managers with valuable insights into workforce attendance and employee productivity over time.

---

## 📌 Project Overview

This dashboard helps HR professionals analyze employee attendance behavior by tracking:

- Employee Count
- Present Percentage
- Work From Home (WFH) Percentage
- Sick Leave Percentage
- Attendance Trends Over Time
- Employee-wise Attendance Summary
- Weekday-wise Attendance Analysis

The dashboard enables organizations to identify attendance patterns, evaluate remote work trends, and make data-driven workforce management decisions.

- Work From Home usage averages around **10%**.
